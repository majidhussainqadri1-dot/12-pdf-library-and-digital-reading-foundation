=== PDF Library and Digital Reading Foundation ===
Requires at least: 6.0
Requires PHP: 7.4
Stable tag: 0.1.0
License: GPLv2 or later

The first 25 percent of an American English encrypted PDF Library and digital reading system.

Features include sixteen fixed document types, sixteen categories, genuine-PDF validation, AES-256-GCM encrypted storage outside Media Library, controlled inline reading, optional downloads, Founder immediate publishing, verified-doctor moderation, public search and filters, cover cards, saves, page bookmarks, progress, private notes, reactions, comments, reports, privacy callbacks, Book/DigitalDocument structured data, and responsive design.

Keep Files 02, 03, 04, 07, 09, and 10 active. Upload and activate this ZIP, test an online-reading-only PDF and a downloadable PDF, then review PDF Library Management before public launch.

Online-only mode removes the download permission and direct public file path, but no browser-based system can honestly guarantee that readable content can never be copied or captured.
